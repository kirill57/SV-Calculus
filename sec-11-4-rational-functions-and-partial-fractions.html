    Section 11.4 Rational functions and partial fractions

    A rational function is a quotient of polynomials:
    🔗
    \begin{equation*} \frac{P(x)}{Q(x)}. \end{equation*}
    Some rational functions are easy to integrate. For example,
    🔗
    \begin{equation*} \int \frac{dx}{x-3} = \ln|x-3|+C, \end{equation*}
    and
    🔗
    \begin{equation*} \int \frac{dx}{x^2+1} = \arctan x+C. \end{equation*}
    Partial fractions turns a complicated rational function into a sum of simple ones. The method is algebra before calculus.
    🔗
    \begin{equation*} \text{factor the denominator, split the fraction, then integrate the pieces.} \end{equation*}

    Subsection Polynomial division

    Partial fractions begins only after the rational function is proper.
    🔗

    Note 11.4.1. Proper rational function.

    A rational function
    🔗
    \begin{equation*} \frac{P(x)}{Q(x)} \end{equation*}
    is called proper if
    🔗
    \begin{equation*} \deg P<\deg Q. \end{equation*}
    🔗
    If the numerator has degree greater than or equal to the denominator, divide first.
    🔗

    Example 11.4.2. Example.

    Find
    🔗
    \begin{equation*} \int \frac{x^3+1}{x-1}\,dx. \end{equation*}
    The rational function is not proper because
    🔗
    \begin{equation*} \deg(x^3+1)=3 \end{equation*}
    and
    🔗
    \begin{equation*} \deg(x-1)=1. \end{equation*}
    Divide:
    🔗
    \begin{equation*} \frac{x^3+1}{x-1} = x^2+x+1+\frac{2}{x-1}. \end{equation*}
    Check:
    🔗
    \begin{equation*} (x-1)(x^2+x+1)=x^3-1. \end{equation*}
    So
    🔗
    \begin{equation*} x^3+1=(x-1)(x^2+x+1)+2. \end{equation*}
    Now integrate:
    🔗
    \begin{equation*} \int \frac{x^3+1}{x-1}\,dx = \int\left(x^2+x+1+\frac{2}{x-1}\right)\,dx. \end{equation*}
    Therefore
    🔗
    \begin{equation*} \int \frac{x^3+1}{x-1}\,dx = \frac{x^3}{3}+\frac{x^2}{2}+x+2\ln|x-1|+C. \end{equation*}
    Polynomial division separates the polynomial part from the proper rational part. Only the proper part needs partial fractions.
    🔗

    Note 11.4.3. First move for rational functions.

    Before partial fractions, ask:
    🔗
    \begin{equation*} \deg P<\deg Q? \end{equation*}
    If not, divide.
    🔗
    🔗
    🔗
    🔗

    Subsection Distinct linear factors

    The simplest partial fractions occur when the denominator factors into distinct linear factors.
    🔗
    For example,
    🔗
    \begin{equation*} (x-1)(x+2) \end{equation*}
    has two different linear factors. We try to write
    🔗
    \begin{equation*} \frac{1}{(x-1)(x+2)} = \frac{A}{x-1}+\frac{B}{x+2}. \end{equation*}
    This helps because each piece has a logarithmic antiderivative.
    🔗

    Seed example.

    Find
    🔗
    \begin{equation*} \int \frac{dx}{(x-1)(x+2)}. \end{equation*}
    Write
    🔗
    \begin{equation*} \frac{1}{(x-1)(x+2)} = \frac{A}{x-1}+\frac{B}{x+2}. \end{equation*}
    Multiply both sides by
    🔗
    \begin{equation*} (x-1)(x+2). \end{equation*}
    Then
    🔗
    \begin{equation*} 1=A(x+2)+B(x-1). \end{equation*}
    This identity must hold for all \(x\) in the domain. Choose values of \(x\) that make terms disappear.
    🔗
    Set \(x=1\text{:}\)
    🔗
    \begin{equation*} 1=A(3)+B(0), \end{equation*}
    so
    🔗
    \begin{equation*} A=\frac13. \end{equation*}
    Set \(x=-2\text{:}\)
    🔗
    \begin{equation*} 1=A(0)+B(-3), \end{equation*}
    so
    🔗
    \begin{equation*} B=-\frac13. \end{equation*}
    Therefore
    🔗
    \begin{equation*} \frac{1}{(x-1)(x+2)} = \frac{1}{3}\frac{1}{x-1} - \frac{1}{3}\frac{1}{x+2}. \end{equation*}
    Now integrate:
    🔗
    \begin{equation*} \int \frac{dx}{(x-1)(x+2)} = \frac13\int\frac{dx}{x-1} - \frac13\int\frac{dx}{x+2}. \end{equation*}
    Thus
    🔗
    \begin{equation*} \int \frac{dx}{(x-1)(x+2)} = \frac13\ln|x-1| - \frac13\ln|x+2| +C. \end{equation*}
    The absolute values belong in the logarithms because \(x-1\) and \(x+2\) can be positive or negative on different intervals.
    🔗

    Note 11.4.4. Distinct linear factors.

    If \(P(x)/Q(x)\) is proper and
    🔗
    \begin{equation*} Q(x)=(x-r_1)(x-r_2)\cdots(x-r_n) \end{equation*}
    has distinct linear factors, then we try
    🔗
    \begin{equation*} \frac{P(x)}{Q(x)} = \frac{A_1}{x-r_1} + \frac{A_2}{x-r_2} +\cdots+ \frac{A_n}{x-r_n}. \end{equation*}
    🔗
    The constants are found by multiplying by the denominator and comparing the resulting polynomial identity.
    🔗
    🔗

    Checkpoint 11.4.5. Why do distinct linear factors produce logarithms?

    Writing \(1/((x-1)(x+2))=A/(x-1)+B/(x+2)\) turns the integral into two logarithms. In your own words, why is that split possible, and why does each simple linear denominator integrate to a logarithm?
    🔗
    Hint.
    Each factor in the denominator is the derivative of itself. Integrating \(1/u\) is the logarithm case of the reverse chain rule.
    🔗
    🔗
    🔗

    Example 11.4.6. Example.

    Decompose
    🔗
    \begin{equation*} \frac{3x+5}{(x-2)(x+1)}. \end{equation*}
    Write
    🔗
    \begin{equation*} \frac{3x+5}{(x-2)(x+1)} = \frac{A}{x-2}+\frac{B}{x+1}. \end{equation*}
    Multiply by \((x-2)(x+1)\text{:}\)
    🔗
    \begin{equation*} 3x+5=A(x+1)+B(x-2). \end{equation*}
    Set \(x=2\text{:}\)
    🔗
    \begin{equation*} 11=3A, \end{equation*}
    so
    🔗
    \begin{equation*} A=\frac{11}{3}. \end{equation*}
    Set \(x=-1\text{:}\)
    🔗
    \begin{equation*} 2=-3B, \end{equation*}
    so
    🔗
    \begin{equation*} B=-\frac23. \end{equation*}
    Thus
    🔗
    \begin{equation*} \frac{3x+5}{(x-2)(x+1)} = \frac{11}{3}\frac{1}{x-2} - \frac{2}{3}\frac{1}{x+1}. \end{equation*}
    So
    🔗
    \begin{equation*} \int \frac{3x+5}{(x-2)(x+1)}\,dx = \frac{11}{3}\ln|x-2| - \frac{2}{3}\ln|x+1| +C. \end{equation*}
    🔗
    🔗

    Subsection Repeated linear factors

    If a linear factor is repeated, one fraction is not enough.
    🔗
    For a denominator containing
    🔗
    \begin{equation*} (x-r)^2, \end{equation*}
    we need both
    🔗
    \begin{equation*} \frac{A}{x-r} \qquad\text{and}\qquad \frac{B}{(x-r)^2}. \end{equation*}
    For a denominator containing
    🔗
    \begin{equation*} (x-r)^3, \end{equation*}
    we need
    🔗
    \begin{equation*} \frac{A}{x-r} + \frac{B}{(x-r)^2} + \frac{C}{(x-r)^3}. \end{equation*}
    Each power must appear.
    🔗

    Note 11.4.7. Repeated linear factor.

    A repeated factor
    🔗
    \begin{equation*} (x-r)^m \end{equation*}
    contributes
    🔗
    \begin{equation*} \frac{A_1}{x-r} + \frac{A_2}{(x-r)^2} +\cdots+ \frac{A_m}{(x-r)^m}. \end{equation*}
    🔗

    Checkpoint 11.4.8. Why does a repeated factor need every power?

    For \((x-r)^2\) in the denominator, both \(A/(x-r)\) and \(B/(x-r)^2\) appear. In your own words, why is one fraction not enough, and what contradiction appears if the highest power is missing?
    🔗
    Hint.
    After clearing the denominator, a missing highest-power term can force \(1=0\) at the repeated root. Every power is needed to span the possible numerators.
    🔗
    🔗
    🔗

    Example 11.4.9. Example.

    Find
    🔗
    \begin{equation*} \int \frac{dx}{(x-1)^2(x+2)}. \end{equation*}
    The denominator contains the repeated factor \((x-1)^2\text{.}\) Therefore write
    🔗
    \begin{equation*} \frac{1}{(x-1)^2(x+2)} = \frac{A}{x-1} + \frac{B}{(x-1)^2} + \frac{C}{x+2}. \end{equation*}
    Multiply by \((x-1)^2(x+2)\text{:}\)
    🔗
    \begin{equation*} 1=A(x-1)(x+2)+B(x+2)+C(x-1)^2. \end{equation*}
    Now choose convenient values.
    🔗
    Set \(x=1\text{:}\)
    🔗
    \begin{equation*} 1=3B, \end{equation*}
    so
    🔗
    \begin{equation*} B=\frac13. \end{equation*}
    Set \(x=-2\text{:}\)
    🔗
    \begin{equation*} 1=9C, \end{equation*}
    so
    🔗
    \begin{equation*} C=\frac19. \end{equation*}
    To find \(A\text{,}\) use any other value, or compare coefficients. Comparing the coefficient of \(x^2\text{,}\)
    🔗
    \begin{equation*} 0=A+C. \end{equation*}
    Thus
    🔗
    \begin{equation*} A=-C=-\frac19. \end{equation*}
    So
    🔗
    \begin{equation*} \frac{1}{(x-1)^2(x+2)} = -\frac{1}{9}\frac{1}{x-1} + \frac{1}{3}\frac{1}{(x-1)^2} + \frac{1}{9}\frac{1}{x+2}. \end{equation*}
    Integrate term by term:
    🔗
    \begin{equation*} \int \frac{dx}{(x-1)^2(x+2)} = -\frac19\int\frac{dx}{x-1} + \frac13\int\frac{dx}{(x-1)^2} + \frac19\int\frac{dx}{x+2}. \end{equation*}
    Since
    🔗
    \begin{equation*} \int (x-1)^{-2}\,dx = -\frac{1}{x-1}, \end{equation*}
    we get
    🔗
    \begin{equation*} \int \frac{dx}{(x-1)^2(x+2)} = -\frac19\ln|x-1| - \frac{1}{3(x-1)} + \frac19\ln|x+2| +C. \end{equation*}

    Note 11.4.10. Why every power is needed.

    If we tried only
    🔗
    \begin{equation*} \frac{A}{x-1}+\frac{C}{x+2}, \end{equation*}
    then after multiplying by the denominator we would get
    🔗
    \begin{equation*} 1=A(x-1)(x+2)+C(x-1)^2. \end{equation*}
    Both terms on the right vanish at \(x=1\text{,}\) giving \(1=0\text{.}\) That is impossible. The missing term \(B/(x-1)^2\) is necessary.
    🔗
    🔗
    🔗
    🔗

    Subsection Irreducible quadratic factors

    Not every quadratic factors into real linear terms. For example,
    🔗
    \begin{equation*} x^2+1 \end{equation*}
    has no real zeros. It is an irreducible quadratic factor over the real numbers.
    🔗
    When such a factor appears, the numerator over it must be linear:
    🔗
    \begin{equation*} \frac{Bx+C}{x^2+1}. \end{equation*}
    A constant numerator alone is not enough. The \(Bx\) part is needed because the derivative of \(x^2+1\) is \(2x\text{,}\) and that derivative produces logarithms.
    🔗

    Note 11.4.11. Irreducible quadratic factor.

    An irreducible quadratic factor
    🔗
    \begin{equation*} ax^2+bx+c \end{equation*}
    contributes a partial fraction of the form
    🔗
    \begin{equation*} \frac{Ax+B}{ax^2+bx+c}. \end{equation*}
    If the quadratic factor is repeated, include one such numerator over each power.
    🔗
    🔗

    Checkpoint 11.4.12. Why does an irreducible quadratic need a linear numerator?

    Over \(x^2+1\) we write \((Bx+C)/(x^2+1)\text{,}\) not a constant alone. In your own words, why is the \(Bx\) term needed, and how does it separate a logarithm coming from the derivative of the quadratic from an arctangent coming from the constant term?
    🔗
    Hint.
    The derivative of \(x^2+1\) is \(2x\text{,}\) which produces \(\ln(x^2+1)\text{.}\) What remains after that piece is peeled off is a constant over \(x^2+1\text{,}\) which is an arctangent.
    🔗
    🔗
    🔗

    Example 11.4.13. Example.

    Find
    🔗
    \begin{equation*} \int \frac{2x+3}{(x-1)(x^2+1)}\,dx. \end{equation*}
    The denominator has one linear factor and one irreducible quadratic factor. Write
    🔗
    \begin{equation*} \frac{2x+3}{(x-1)(x^2+1)} = \frac{A}{x-1} + \frac{Bx+C}{x^2+1}. \end{equation*}
    Multiply both sides by \((x-1)(x^2+1)\text{:}\)
    🔗
    \begin{equation*} 2x+3=A(x^2+1)+(Bx+C)(x-1). \end{equation*}
    Expand:
    🔗
    \begin{equation*} 2x+3 = Ax^2+A+Bx^2-Bx+Cx-C. \end{equation*}
    Collect terms:
    🔗
    \begin{equation*} 2x+3 = (A+B)x^2+(-B+C)x+(A-C). \end{equation*}
    Now match coefficients.
    🔗
    For \(x^2\text{:}\)
    🔗
    \begin{equation*} A+B=0. \end{equation*}
    For \(x\text{:}\)
    🔗
    \begin{equation*} -B+C=2. \end{equation*}
    For the constant term:
    🔗
    \begin{equation*} A-C=3. \end{equation*}
    Solving gives
    🔗
    \begin{equation*} A=\frac52, \qquad B=-\frac52, \qquad C=-\frac12. \end{equation*}
    Therefore
    🔗
    \begin{equation*} \frac{2x+3}{(x-1)(x^2+1)} = \frac{5}{2}\frac{1}{x-1} + \frac{-\frac52x-\frac12}{x^2+1}. \end{equation*}
    Now integrate:
    🔗
    \begin{equation*} \int \frac{2x+3}{(x-1)(x^2+1)}\,dx = \frac52\int\frac{dx}{x-1} -\frac52\int\frac{x}{x^2+1}\,dx -\frac12\int\frac{dx}{x^2+1}. \end{equation*}
    The three pieces are
    🔗
    \begin{equation*} \int\frac{dx}{x-1}=\ln|x-1|, \end{equation*}
    \begin{equation*} \int\frac{x}{x^2+1}\,dx=\frac12\ln(x^2+1), \end{equation*}
    and
    🔗
    \begin{equation*} \int\frac{dx}{x^2+1}=\arctan x. \end{equation*}
    Thus
    🔗
    \begin{equation*} \int \frac{2x+3}{(x-1)(x^2+1)}\,dx = \frac52\ln|x-1| - \frac54\ln(x^2+1) - \frac12\arctan x +C. \end{equation*}
    The quadratic piece produces two kinds of antiderivatives: a logarithm from the derivative of the denominator, and an arctangent from the remaining constant part.
    🔗
    🔗
    🔗

    Subsection Completing the square

    Quadratic denominators often need one more algebraic step. Complete the square.
    🔗
    The basic pattern is
    🔗
    \begin{equation*} x^2+4x+13=(x+2)^2+9. \end{equation*}
    This turns the denominator into the arctangent form
    🔗
    \begin{equation*} u^2+a^2. \end{equation*}

    Example 11.4.14. Example.

    Find
    🔗
    \begin{equation*} \int \frac{3x+7}{x^2+4x+13}\,dx. \end{equation*}
    Let
    🔗
    \begin{equation*} D(x)=x^2+4x+13. \end{equation*}
    Then
    🔗
    \begin{equation*} D'(x)=2x+4. \end{equation*}
    The numerator \(3x+7\) can be split into a multiple of \(D'(x)\) plus a remainder:
    🔗
    \begin{equation*} 3x+7 = \frac32(2x+4)+1. \end{equation*}
    Therefore
    🔗
    \begin{equation*} \int \frac{3x+7}{x^2+4x+13}\,dx = \frac32\int \frac{2x+4}{x^2+4x+13}\,dx + \int \frac{dx}{x^2+4x+13}. \end{equation*}
    The first integral is logarithmic:
    🔗
    \begin{equation*} \frac32\int \frac{2x+4}{x^2+4x+13}\,dx = \frac32\ln|x^2+4x+13|. \end{equation*}
    For the second integral, complete the square:
    🔗
    \begin{equation*} x^2+4x+13=(x+2)^2+9. \end{equation*}
    So
    🔗
    \begin{equation*} \int \frac{dx}{x^2+4x+13} = \int\frac{dx}{(x+2)^2+3^2}. \end{equation*}
    Let
    🔗
    \begin{equation*} u=x+2. \end{equation*}
    Then
    🔗
    \begin{equation*} du=dx, \end{equation*}
    and
    🔗
    \begin{equation*} \int\frac{dx}{(x+2)^2+3^2} = \int\frac{du}{u^2+3^2} = \frac13\arctan\left(\frac{u}{3}\right)+C. \end{equation*}
    Return to \(x\text{:}\)
    🔗
    \begin{equation*} \int \frac{dx}{x^2+4x+13} = \frac13\arctan\left(\frac{x+2}{3}\right)+C. \end{equation*}
    Putting the two parts together gives
    🔗
    \begin{equation*} \int \frac{3x+7}{x^2+4x+13}\,dx = \frac32\ln(x^2+4x+13) + \frac13\arctan\left(\frac{x+2}{3}\right) +C. \end{equation*}
    Here the denominator is always positive, so the absolute value in the logarithm is not needed. In the general formula \(\int D'(x)/D(x)\,dx=\ln|D(x)|+C\text{,}\) the absolute value is still the safest habit.
    🔗
    🔗
    🔗

    Subsection The partial fractions pattern

    The method is systematic.
    🔗

    Note 11.4.15. Partial fractions workflow.

    🔗
    The building blocks are few.
    🔗
    \begin{equation*} \int \frac{dx}{x-r}=\ln|x-r|+C, \end{equation*}
    \begin{equation*} \int \frac{dx}{(x-r)^m} = \frac{(x-r)^{1-m}}{1-m}+C, \qquad m\neq1, \end{equation*}
    \begin{equation*} \int \frac{D'(x)}{D(x)}\,dx=\ln|D(x)|+C, \end{equation*}
    and
    🔗
    \begin{equation*} \int \frac{dx}{(x-h)^2+a^2} = \frac1a\arctan\left(\frac{x-h}{a}\right)+C. \end{equation*}
    Partial fractions is not a new antiderivative rule. It is a way of forcing a rational function to break into pieces whose antiderivatives we already know.
    🔗

    A final example.

    Find
    🔗
    \begin{equation*} \int \frac{x^2+2x+4}{x(x+1)^2}\,dx. \end{equation*}
    The function is proper because the numerator has degree \(2\) and the denominator has degree \(3\text{.}\)
    🔗
    The denominator has a distinct factor \(x\) and a repeated factor \((x+1)^2\text{.}\) Write
    🔗
    \begin{equation*} \frac{x^2+2x+4}{x(x+1)^2} = \frac{A}{x} + \frac{B}{x+1} + \frac{C}{(x+1)^2}. \end{equation*}
    Multiply by \(x(x+1)^2\text{:}\)
    🔗
    \begin{equation*} x^2+2x+4 = A(x+1)^2 + Bx(x+1) + Cx. \end{equation*}
    Set \(x=0\text{:}\)
    🔗
    \begin{equation*} 4=A, \end{equation*}
    so
    🔗
    \begin{equation*} A=4. \end{equation*}
    Expand the right side:
    🔗
    \begin{equation*} 4(x+1)^2+Bx(x+1)+Cx. \end{equation*}
    That is
    🔗
    \begin{equation*} 4(x^2+2x+1)+B(x^2+x)+Cx. \end{equation*}
    Collect terms:
    🔗
    \begin{equation*} (4+B)x^2+(8+B+C)x+4. \end{equation*}
    Match with
    🔗
    \begin{equation*} x^2+2x+4. \end{equation*}
    Thus
    🔗
    \begin{equation*} 4+B=1, \end{equation*}
    so
    🔗
    \begin{equation*} B=-3. \end{equation*}
    Also,
    🔗
    \begin{equation*} 8+B+C=2. \end{equation*}
    Since \(B=-3\text{,}\)
    🔗
    \begin{equation*} 8-3+C=2, \end{equation*}
    so
    🔗
    \begin{equation*} C=-3. \end{equation*}
    Therefore
    🔗
    \begin{equation*} \frac{x^2+2x+4}{x(x+1)^2} = \frac{4}{x} - \frac{3}{x+1} - \frac{3}{(x+1)^2}. \end{equation*}
    Integrate:
    🔗
    \begin{equation*} \int \frac{x^2+2x+4}{x(x+1)^2}\,dx = 4\ln|x| - 3\ln|x+1| + \frac{3}{x+1} +C. \end{equation*}
    So
    🔗
    \begin{equation*} \int \frac{x^2+2x+4}{x(x+1)^2}\,dx = 4\ln|x| - 3\ln|x+1| + \frac{3}{x+1} +C. \end{equation*}
    We now have several strong methods: substitution, integration by parts, trigonometric identities, trigonometric substitution, and partial fractions. The difficult part is no longer only carrying out a method. It is choosing the method. That is the next question.
    🔗
    🔗

    Checkpoint 11.4.17. Why is partial fractions algebra before calculus?

    The method begins only after the rational function is proper, and it splits one complicated fraction into simpler pieces. In your own words, why must you divide first when the numerator’s degree is too large, and why is the integration step almost an afterthought?
    🔗
    Hint.
    The pieces \(1/(x-r)\) and \((Ax+B)/(x^2+1)\) already have known antiderivatives. The work is rewriting the integrand so those pieces appear.
