## Main corrections

- **Numerical and worked-answer errors:** the Chapter 1 trip travels 175 miles, with average speed 175/6, although its signed displacement is 115 miles. Its second signed-area rectangle is +75. Three Gaussian midpoint entries in 12.1, a Newton rounding claim, harmonic-block bar heights, and a six-decimal sine enclosure were corrected and recalculated.
- **Missing justifications and premature dependencies:** 5.6 now proves existence of the exponential defining slope and uniqueness of the base e using earlier continuity, exponent laws, dyadic bisection, and completeness. Square-root limits, inverse differentiability exercises, and monotonicity claims no longer silently depend on later results. Chapter 12 extrapolation uses a finite remainder from repeated integration before Chapter 16 introduces Taylor theory. Euler's formula now precedes its first consequence. The first-variation argument supplies an explicit supported C2 variation and checks its zero extension. These three substantial proof repairs received a second written review during integration.
- **Hypotheses, definitions, and logical implications:** endpoint assumptions in MVT corollaries, density versus geometric centroid, signed versus unsigned motion, shell/surface radii, probability normalization bounds, improper-integral definitions, and conditional convergence statements were repaired. The total pumping-work formula now has definite fluid-height bounds. Decay faster than 1/x is no longer claimed sufficient for integrability. Stability is distinguished from asymptotic stability, and uniqueness is no longer asserted without conditions. Complex convergence, integration, and symmetric Fourier sums are defined before use.
- **Organization and teaching:** transitions now account for the inserted material; ambiguous problems specify their models and domains; irrelevant duplicate tables were replaced; cleared-denominator identities and CAS checks state their proper scope. Section openings and other flagged prose were revised to state the actual concept or assumption in simple language.
- **Figures:** corrections include two reversed logistic phase arrows, clipped spirals/circles/conics, missing chord geometry, misleading nested-interval scales, inverse-graph scales, wrongly positioned Newton geometry, transparent excluded points, overlapping labels, and a curve legend that inherited shading styles. All affected vector assets were regenerated.
- **Typesetting:** a paragraph swallowed by a heading, literal array-spacing text such as `[2mm]`, raw TeX in prose, clipped table formulas, split mathematical units, an overflowing method display, and a tab that erased a convergence arrow were repaired. A source check now flags tabs in inline mathematics, since malformed notation can otherwise render without a MathJax error. Publication markup now validates against the installed PreTeXt schema. The external-assets declaration is in docinfo and the reproducible CLI version is pinned to 2.53.0.

## Validation and publication

[final-validation.json](audit-2026-10-17/final-validation.json) binds the final source fingerprint to the checked HTML hashes. It records schema, structure, numerical, browser, visual-review, and original-edition checks. No unresolved manuscript/schema, MathJax, missing-image, JavaScript, or page-overflow errors remain in the checked HTML. The HTML build command is `pretext build web --no-generate`, after regenerating changed vector assets with `pretext generate latex-image -t web -q`.

The local preview is served by `pretext view web`. Publication uses `pretext deploy`, the supported GitHub Pages command in PreTeXt 2.53.0; this CLI has no `pretext publish` subcommand. Source changes are committed on main and synchronized normally to origin; PreTeXt manages the generated gh-pages branch.

On this Windows workstation, copied staging directories can retain the read-only attribute. If deployment cannot remove `output/stage/external/images`, clear that attribute only within the generated staging directory before retrying `pretext deploy`. The successful release used this procedure after verifying the resolved staging path and confirming that it contained no links. Source assets were preserved.

The [public build record](https://kirill57.github.io/SV-Calculus/audit-build.json) identifies the exact source commit, source fingerprint, HTML hashes, and referenced-asset hashes. The post-publication check opens all 249 live pages again, expands all hints, and compares live HTML and referenced assets byte for byte with the validated local build. Its local receipt is `output/publication-verification.json`, with browser details in `qa/audit-2026-10-17/live-after/`. A publication is complete only after those comparisons pass.
